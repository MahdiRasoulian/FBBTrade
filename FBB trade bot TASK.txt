# 1. CORE TRADING CONCEPT

The primary trading concept is **Fibonacci Bollinger Bands (FBB)**.

The original TradingView script supplied as the reference is:

```pine
study(shorttitle="FBB", title="Fibonacci Bollinger Bands", overlay=true)

length = input(200, minval=1)
src = input(hlc3, title="Source")
mult = input(3.0, minval=0.001, maxval=50)

basis = vwma(src, length)
dev = mult * stdev(src, length)

upper_1 = basis + (0.236 * dev)
upper_2 = basis + (0.382 * dev)
upper_3 = basis + (0.5 * dev)
upper_4 = basis + (0.618 * dev)
upper_5 = basis + (0.764 * dev)
upper_6 = basis + (1 * dev)

lower_1 = basis - (0.236 * dev)
lower_2 = basis - (0.382 * dev)
lower_3 = basis - (0.5 * dev)
lower_4 = basis - (0.618 * dev)
lower_5 = basis - (0.764 * dev)
lower_6 = basis - (1 * dev)

plot(basis, color=fuchsia, linewidth=2)
```

# 2. UNDERSTAND FBB CORRECTLY

The FBB calculation is fundamentally:

```text
Source = HLC3

Basis = VWMA(Source, Length)

Deviation = Multiplier × StandardDeviation(Source, Length)

Upper Level:
Basis + FibonacciRatio × Deviation

Lower Level:
Basis - FibonacciRatio × Deviation
```

Default parameters:

```text
Length = 200
Source = HLC3
Multiplier = 3.0
```

Levels:

```text
0.236
0.382
0.500
0.618
0.764
1.000
```

There are therefore 12 bands plus the central VWMA basis.

Important:

These are NOT classical Fibonacci retracement levels derived from a swing high and swing low.

They are Fibonacci-scaled volatility bands around a VWMA.

Do not confuse:

```text
Fibonacci Bollinger Bands
```

with:

```text
Fibonacci Swing Retracement
```

They are mathematically and conceptually different.

# 3. TRADING INTERPRETATION

As a senior trader, understand the following before writing the trading logic.

An FBB level is a **price-location / volatility event**, not automatically an entry signal.

For example:

```text
Price reaches Upper 0.764
```

does NOT automatically mean:

```text
SELL
```

Likewise:

```text
Price reaches Lower 0.764
```

does NOT automatically mean:

```text
BUY
```

A strong trend can cause price to remain near or beyond an outer FBB band.

Therefore the system must distinguish between:

### A. Level Touch

Price reaches or enters an FBB level.

### B. Reaction

Price reaches the level and demonstrates configured rejection/response behavior.

### C. Confirmation

The Entry Machine determines whether the reaction satisfies the configured entry rules.

### D. Entry

Only after confirmation should an Entry Signal be produced.

The architecture must support these concepts independently.
